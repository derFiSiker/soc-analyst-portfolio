# Security Policy

Dieses Repository dokumentiert ausschließlich ein eigenes, isoliertes Lernlabor. Bitte keine echten Zugangsdaten, Wazuh-Enrollment-Keys, API-Tokens, Zertifikate, Session-Cookies, privaten Hostpfade, MAC-Adressen oder Rohlogs mit unnötigen personenbezogenen Daten veröffentlichen.

Wenn ein Geheimnis versehentlich committed wurde, wird es nicht nur aus der Arbeitskopie gelöscht, sondern unverzüglich widerrufen oder rotiert. Dieses Repository enthält keine produktiven Systeme und keine externen Zielsysteme.
