# GitHub-Repository-Starter

Erstelle unter dem GitHub-Konto `derFiSiker` fünf neue, zunächst leere Repositories mit den Namen der Unterordner. Lade jeweils den vollständigen Inhalt des passenden Unterordners hoch. Die Portfolio-Buttons verweisen bereits auf genau diese Repository-Namen.

Die Inhalte dokumentieren ausschließlich kontrollierte Homelab-Szenarien. Ergänze reale Screenshots, bereinigte Konfigurationsauszüge, Sigma-Regeln und eigene Analyseartefakte erst nach einer Prüfung auf Zugangsdaten, IP-Adressen und personenbezogene Daten.
