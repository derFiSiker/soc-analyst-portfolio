# Texte in Visual Studio Code ändern

Alle sichtbaren deutschen und englischen Website-Texte sowie die Antworten des Hero-Terminals stehen zentral in [`client/src/content/portfolioContent.ts`](client/src/content/portfolioContent.ts). Diese Datei kann direkt in Visual Studio Code geöffnet und bearbeitet werden.

Die Bereiche `de` und `en` enthalten die jeweiligen Sprachversionen. Ändere nur die Texte innerhalb der Anführungszeichen und lasse die technischen Schlüssel wie `hero`, `projects`, `terminal` oder `commands` unverändert. Im Bereich `terminal.commands` kann ein neuer Befehl ergänzt werden, wenn derselbe Befehl auch in der zweiten Sprache angelegt wird. Der Befehl `clear` ist bereits eingebaut und muss nicht konfiguriert werden.
