# Ransomware Behavior Detection

Eine verhaltensbasierte Case Study, die Datei-, Registry-, Prozess- und Netzwerksignale in einem sicheren Übungsrahmen zusammenführt.

## Ziel

Mehrere schwache Signale zeitlich verknüpfen und daraus eine priorisierbare Untersuchungshypothese, dokumentierte Triage sowie Wiederherstellungs- und Eskalationsschritte ableiten.

## Beobachtungsebenen

| Ebene | Beispielhafte Beobachtung |
|---|---|
| Endpoint | Ungewöhnliche Datei- oder Prozessaktivität |
| Registry | Relevante Konfigurationsveränderungen |
| Netzwerk | Auffällige ausgehende Kommunikation |
| Response | Triage-, Eskalations- und Wiederherstellungsnotizen |
