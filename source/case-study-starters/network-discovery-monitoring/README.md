# Network Discovery Monitoring

Diese Case Study modelliert Netzwerkerkundung als beobachtbares Verhalten. Sie verbindet Port-Muster, Zielbreite und Zeitfenster mit Endpoint- und Netzwerk-Telemetrie.

## Ziel

Kontrollierte Discovery-Aktivität von regulärem Administrationsverkehr abgrenzen und daraus testbare Detection-Hypothesen ableiten.

## Homelab-Kontext

| Werkzeug oder Quelle | Beitrag |
|---|---|
| Kali Linux | Kontrollierte Discovery-Simulation im isolierten Lab |
| Wazuh | Zentrale Analyse und Alert-Kontext |
| Wireshark | Paket- und Protokollkontext |
| Windows/Linux Endpoints | Sichtbare Zielsysteme |
