# Evidence-Verzeichnis

Lege hier ausschließlich bereinigte Room-00-Nachweise ab. Rohlogs, `.evtx`, Packet Captures, Passwörter, Enrollment-Keys, Tokens, Cookies, MAC-Adressen und private Hostpfade gehören nicht in dieses Verzeichnis.

Empfohlene Dateien:

```text
topology-sanitized.png
wazuh-health-sanitized.png
agents-active-sanitized.png
network-validation.txt
```

Jede Datei muss im `templates/evidence-index.md` mit Aussage und Zeitpunkt eingetragen werden.
